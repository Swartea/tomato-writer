# 番茄短篇写作台

面向个人作者的本地优先 VS Code 写作扩展。支持男频、女频、悬疑三类短篇创作，从策划、文风、大纲到逐章生成、审校和人工审批。

## 核心原则

- 每本小说是一个独立项目，默认保存在“文稿/番茄写作项目”项目库中。
- 新项目的正文、策划、大纲和资产均为可直接查看和备份的 UTF-8 TXT 文件。
- API Key 使用 VS Code SecretStorage，不写入项目或导出文件。
- AI 只生成候选稿，不能直接覆盖正式正文。
- 候选稿经过节奏、一致性和文风审校，由作者最终批准。

## 使用

1. 执行“番茄写作助手：新建写作项目”。
2. 扩展会在默认项目库中创建小说文件夹；也可选择其他位置。
3. 从左侧“我的项目”选择小说，在“项目文件”中可直接展开正文、策划、
   资产等真实文本文件，单击即可用 VS Code 编辑器打开。
4. 在“策划与文风”填写本书独立标准。
5. 在“剧情大纲”按阶段维护每章目标、人物立场、关键事件、冲突、转折、
   情绪回报、伏笔、上下章衔接和章末钩子；也可让 AI 生成详细结构。
6. 在“创作资产”维护人物、世界观和伏笔。
7. 在“写作与审批”查看 AI 上下文，生成候选并批准正式稿。
8. 在“统计”导出 TXT 或 Markdown。

## 本地开发

```bash
npm install
npm test
npm run build
```

根目录使用 npm workspaces 管理核心包、协议包和 Webview。按 F5 启动 Extension Development Host；打包使用 `npm run package`。

## 数据安全

新项目采用原子写入；批准候选稿前会在项目的 `备份/` 生成快照。旧版
`.md + JSON` 项目仍可原样使用，也可通过“迁移为易读 TXT”复制到项目库；
迁移不会删除或改写源项目。仍建议将整个项目库纳入 Time Machine 或其他个人备份方案。

当前版本是本地单用户工具，不包含账号、云同步、多人协作或遥测。
