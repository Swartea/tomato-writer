# 开篇策略：照着改，番茄读者就划不动手指

很多作者在番茄扑街，不是故事不行，是头两屏就把人劝退了。番茄的读者拇指比脑子快——划得不爽，三秒就走，算法一看留存低，书就死在摇篮里。这份东西不跟你讲大道理，只说开篇头几屏到底该怎么落笔。

---

## 一、先把账算明白：番茄到底在看什么

平台不是编辑，是个冷冰冰的算法。它只认几个数。

首章留存最要命。读者点进第 1 章，有没有读完、有没有点第 2 章，这个数字权重最高。然后是追读率——看完前 3 章的人里，第 4 章还回来的有多少。所谓"黄金三章"，就是专门为追读率服务的。完读，加上段评、投票这类轻互动，会反过头来帮你推量。还有个最容易被忽略的：书名、简介、首章三者是不是一伙的。读者被简介勾进来，首章却不是那回事，扭头就走，算法直接给你贴"低质"。

所以开篇只干一件事：用最短的篇幅，把人设、冲突、钩子、一颗糖一次性塞给读者，让他第 1 章末尾手指自己就点了下一章。

---

## 二、首句定生死：前三行必须过关

番茄读者不"翻开书"，他们是"刷"进来的。你只有一部手机屏的机会——大概 200 到 300 字（经验值，按自己读者画像调）。首句必须满足三选一：

- **一个动作**，最好带冲突
- **一个冲突**，最好带人物
- **一个反常**，打破常识的事

反过来全是死法，开场千万别碰：
- 环境描写起手："天空阴沉沉的，乌云压城……"——读者：关我啥事。
- 内心独白起手："我叫林轩，是个孤儿……"——没冲突，划走。
- 背景交代起手："这是一个以武为尊的大陆……"——设定再牛，读者先睡。

正例：
> 林轩今天差点死。大师兄把他从天台一脚踹了下去。
> 我杀了我丈夫。可法医说，他三天前就死了。
> 系统到账的那一刻，全班最丑的女生突然朝我笑了。

反例（别这么写）：
> 清晨的阳光洒在青云宗的屋檐上，新的一天开始了。（环境，无冲突）
> 我叫苏晚，今年二十二岁，是个普通的上班族。（独白，无钩子）

## 三、分题材打：男频、女频、悬疑不是一套打法

通版策略最容易害人的地方，就是不分赛道。下面三套，你认准自己那类照着来。

### 男频（玄幻 / 都市 / 历史 / 爽文）
读者来要的是"爽"和"逆"。核心情绪就俩字：不甘。
开片节奏：被欺压 → 金手指亮 → 小试牛刀。
钩子库：重生复仇、废柴觉醒、系统到账、被退婚、兄弟背刺、全村的希望。
首章给的"糖"= 打脸或信息差——让主角用读者知道、配角不知道的东西，悄悄占上风。

### 女频（甜宠 / 古言 / 言情 / 虐恋）
读者来要的是"被爱"和"心疼"。核心情绪：想被偏爱。
开片节奏：关系先错位（替身 / 契约 / 先婚后爱）→ 反差男主出现 → 一颗糖。
钩子库：重生悔婚、读心术、替身反转、带球跑、追妻火葬场开场。
首章给的"糖"= 心动瞬间或被偏爱的感觉，不是打脸。一个眼神、一句反常的温柔，比一场架更留人。

### 悬疑 / 脑洞（推理 / 无限流 / 诡秘）
读者来要的是"不安"和"想知道"。核心情绪：细思极恐。
开片节奏：反常事件砸脸 → 抛线索碎片 → 露一点规则。
钩子库：死亡预告、规则怪谈、记忆缺失、密室、不可信叙事。
首章给的"糖"= 拼图感——"原来如此"的那一下爽，比打脸更上头。

## 四、黄金三章：照这个骨架填

**第 1 章 · 困境爆点**：把主角扔进一个具体、难堪、要命的局里，末尾抛钩子（悬念 / 反转 / 金手指征兆都行），留一个"然后呢"的强问号。

**第 2 章 · 转机落地**：金手指、重生记忆、系统、秘密身份，挑一样亮出来。让主角小试牛刀，给读者一颗糖——这颗糖是什么，看上面你那类题材的定义。

**第 3 章 · 升级打脸**：第一次正面冲突收口，配角吃瘪，主线悬念正式铺开。章末再抛一个更大的钩子，把人逼进第 4 章。

---

## 五、钩子不是名词，是手艺：六种写法 + 怎么套自己身上

下面这六个，不是让你抄，是让你照着"结构"改自己的开篇。

1. **危机钩子**：结婚三年，老婆第一次主动吻我，唇上却抵着一把刀。（生死 + 背叛，一屏炸开）
2. **反差钩子**：全宗门都笑我废柴，直到我剑指苍穹时天黑了半边。
3. **金手指钩子**：重生回高考前一天，我先把前世害死我的人写进了黑名单。
4. **情绪共鸣钩子**：加班到凌晨三点，银行卡三位数，房东说再不交租东西扔出去。
5. **悬念钩子**：我捡了本日记，最后一页写——别信你身边任何一个活人。
6. **对话炸场钩子**："你敢动她一下试试。"他声音很轻，"试试你就知道了。"

**套法**：拿你自己的第 1 章开头，问自己——这一句里，是动作、冲突、还是反常？如果都不是，把它换成上面任意一种的结构，只换你的人物和处境，钩子立刻立住。

## 六、落到字上：句怎么写才抓人

手机上读者靠"划"，不靠"读"。几条铁规矩：

**句子别长。** 一句尽量压在 25 字内（经验值），三行必换行。长句拆碎，制造紧张：门开了。风灌进来。她站在门口，浑身是血。

**少用形容词，多用动词。** 把"他愤怒地狠狠一脚踹翻桌子"改成"他抬脚，桌子翻了"。情绪让读者自己补。

**别解释，演给他看。** 不写"他很害怕"，写"手在抖，钥匙插了三次没进锁孔"。

**章末别收平。** 每章最后一句，要么悬念要么反转，绝不在章末说"这一天就这样过去了"。

**说人话。** 读者要听你讲故事，不是读散文。能用"咋"就别用"如何"。

## 七、这些坑，番茄编辑一眼就烦（负面清单）

以下几条，踩中任意一条开篇基本废了：
- **开局无敌 / 龙傲天**：主角一上来啥都碾压，没有起伏，读者秒腻。
- **大段诗词、文言文、掉书袋**：手机上谁看这个。
- **回忆杀、前情提要超过一屏**：还没进故事先疲劳。
- **多 POV 乱切**：开篇就换视角，读者记不住谁是谁。
- **圣母 / 无脑善良主角**：现代读者不爱。
- **水字数**：重复心理活动、无意义环境描写凑篇幅，算法识别得出来。
- **标题党 / 简介货不对板**：承诺的和写的不一样，留存断崖。
- **敏感 / 擦边内容**：直接下架，别碰。

---

## 八、书名、简介、首章，得是一伙的

最常见的扑街：简介写得天花乱坠，首章根本没接住，读者感觉被骗。对齐方法很简单——简介抛的钩子，首章必须接。三条简介模板，挑和你书搭的：

- **反差型**："人人都以为她是废柴，直到那天……"
- **悬念型**："我杀了人，可凶手是十年后的我。"
- **爽点型**："重生一次，欠我的，我一个个清算。"

写完首章，回头看简介：承诺的爽点，首章给到了吗？没给就改首章，别改简介去将就。

---

## 九、发布前，拿这套客观标准过一遍

别问"读者会不会想看"，问这些能打勾的：
- [ ] 首句是动作 / 冲突 / 反常吗？（不是就改）
- [ ] 前 3 段里有没解开的悬念吗？
- [ ] 每章末句是钩子或反转吗？
- [ ] 金手指 / 核心设定，前 3 章亮了吗？
- [ ] 有没有超过一屏的背景 / 回忆堆砌？（有就砍）
- [ ] 简介承诺的爽点，首章交付了吗？
- [ ] 踩了第七条负面清单任一条吗？（踩了就改）

## 十、改前改后：看差距在哪

**男频例：**
改前（铺垫，弱）：林轩是青云宗外门弟子，平日刻苦但天赋平平，常被人嘲笑。这一日，他又在天台打坐……
改后（冲突 + 钩子，强）：林轩今天差点死。不是修炼走火，是大师兄把他从天台踹了下去——只因他多看了一眼宗主的女儿。
差别：背景全删，首句即危机；用具体事件替掉"被嘲笑"的概括；埋"为什么多看一眼就要死"的钩子。

**女频例：**
改前（独白，弱）：苏晚今年二十二，是个普通上班族，最大的愿望就是安稳过日子。直到那个雨夜……
改后（关系错位 + 糖，强）：结婚三年，顾沉从没碰过她。可今早，她在丈夫手机里，看见自己明天车祸身亡的提醒。
差别：首句立住反常关系，第二句砸悬念，读者立刻想知"他是不是凶手 / 能不能救她"。
