# 开片策略文案 · 测试报告与优化计划

> 测试对象：`开片策略-番茄优化版.md`（v1）
> 测试视角：番茄小说平台契合度 + 文案说服力 + AI 写作痕迹
> 产出目标：将"通用 AI 清单"升级为"可直接落地的番茄向作战手册"

---

## A. 测试结论（v1 诊断）

| 维度 | 问题 | 严重度 |
|---|---|---|
| 题材适配 | 全篇通版，未区分男频/女频/悬疑脑洞；三类开片打法差异极大 | 🔴 P0 |
| 首句标准 | 只说"钩子钉第一屏"，缺首句硬标准（动作/冲突/反常，禁环境/内心/背景） | 🔴 P0 |
| AI 味 | "小标题+冒号+解释"模板腔贯穿；枚举式"本质="总结为典型 AI 痕迹 | 🔴 P0 |
| 负面清单 | 番茄编辑反感的（开局无敌、大段诗词、回忆杀、多POV、圣母、水字数）全缺 | 🔴 P0 |
| 简介协同 | 提了"书名+简介+首章一致"，但无"简介怎么写"指法 | 🟡 P1 |
| 自检清单 | 多为"读者会不会…"主观问句，无法自检 | 🟡 P1 |
| 微型爽点 | "打脸/信息差"偏男频，未泛化到女频/悬疑 | 🟡 P1 |
| 数据出处 | "一屏200–300字""一句≤25字"为经验值却未标注 | 🟢 P2 |
| 钩子迁移 | 仅给句式，缺"你自己的开篇怎么套"的指引 | 🟢 P2 |

---

## B. 优化目标

让策略从"看起来很全的清单"变成"作者照着就能改开篇"的作战手册：
- 去 AI 腔，读起来像老编辑在当面说。
- 按题材分轨，给不同赛道的钩子库。
- 首句、章末、简介三处给硬标准。
- 补"千万别做"的负面清单 + 客观化自检。

---

## C. 优化计划（分档）

### P0 — 必改
1. **去 AI 味**：破"小标题+冒号+解释"模板腔；结论句改人话；示例加口语批注。
2. **题材分轨**：男频 / 女频 / 悬疑脑洞 各一套开片打法 + 各自钩子库。
3. **首句硬标准**：首句三选一 = 动作 / 冲突 / 反常；禁止环境描写、内心独白、背景交代开场。
4. **负面清单**：列出番茄编辑明确反感的开局写法（开局无敌、大段诗词、回忆杀、多POV乱切、圣母、水字数等）。

### P1 — 强改
5. **简介协同**："承诺—交付"对齐法 + 3 个简介模板（吸睛但不货不对板）。
6. **自检客观化**：主观问句 → 可勾选客观标准（如"章末是否留未解悬念"）。
7. **糖分题材**：男频=打脸/信息差；女频=心动/被偏爱；悬疑=线索拼图感。

### P2 — 润色
8. 数据标注"经验值/可调"。
9. 钩子示例补"改造迁移"指引。
10. 结构重排：算法 → 首句标准 → 题材分轨 → 三章模板 → 钩子库 → 文字优化 → 负面清单 → 自检 → 示例。
