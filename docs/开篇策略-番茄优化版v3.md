# 开篇策略：照着改，番茄读者就划不动手指

很多作者在番茄扑街，真不是故事不行，是头两屏把人劝退了。番茄读者拇指比脑子快——划得不爽，三秒就走，算法一看留存低，书直接死在摇篮里。我在这行待得久，见过太多好点子毁在开篇。下面这些不是大道理，是你下笔前该刻进骨头的几件事。

---

## 一、先把账算明白：番茄在看什么

平台不是编辑，是冷冰冰的算法，只认几个数。

- **首章留存最要命**：读者点进第 1 章，读完没、点第 2 章没，权重最高。
- **追读率**：看完前 3 章的人里，第 4 章还回来的有多少。"黄金三章"就是给它服务的。
- **完读 + 段评投票**这类轻互动，反过头来帮你推量。
- **书名、简介、首章得是一伙的**：读者被简介勾进来，首章不是那回事，扭头就走，算法贴你"低质"。

说白了，开篇只干一件事：用最短篇幅，把人设、冲突、钩子、一颗糖一次性塞给读者，让他第 1 章末尾手指自己点了下一章。

---

## 二、首句定生死

番茄读者不"翻书"，是"刷"进来的。你只有一部手机屏——大概一两百到三百字（这数别死记，去翻你同类爆款前 3 章数平均句长，照那个调）。首句必须满足三选一：

- **一个动作**，最好带冲突
- **一个冲突**，最好带人物
- **一个反常**，打破常识

反过来全是死法，开场别碰：
- 环境起手："天空阴沉沉的……"——关我啥事
- 独白起手："我叫林轩，是个孤儿……"——没冲突，划走
- 背景起手："这是个以武为尊的大陆……"——设定再牛，读者先睡

正例：
> 我杀了我丈夫。可法医说，他三天前就死了。
> 系统到账那一刻，全班最安静的女生突然朝我笑了。
> 师父咽气前塞给我半块玉佩，说千万别让师兄看见。

反例（别这么写）：
> 清晨的阳光洒在青云宗屋檐上，新的一天开始了。（环境，无冲突）
> 我叫苏晚，今年二十二，普通上班族。（独白，无钩子）

---

## 三、分题材打，别一套通吃

通版策略最坑人的，就是不分赛道。认准你那类：

**男频（玄幻 / 都市 / 历史 / 爽文）**
读者来要"爽"和"逆"，核心情绪就俩字：不甘。
开片节奏：被欺压 → 金手指亮 → 小试牛刀。
首章的"糖"= 打脸或信息差——让主角用读者知道、配角不知道的东西，悄悄占上风。

**女频（甜宠 / 古言 / 言情 / 虐恋）**
读者来要"被爱"和"心疼"，核心情绪：想被偏爱。
开片节奏：关系先错位（替身 / 契约 / 先婚后爱）→ 反差男主出现 → 一颗糖。
首章的"糖"= 心动或被偏爱的感觉，不是打脸。一个眼神、一句反常的温柔，比一场架更留人。

**悬疑 / 脑洞（推理 / 无限流 / 诡秘）**
读者来要"不安"和"想知道"，核心情绪：细思极恐。
开片节奏：反常事件砸脸 → 抛线索碎片 → 露一点规则。
首章的"糖"= 拼图感——"原来如此"那一下，比打脸更上头。

---

## 四、黄金三章，按你的赛道填

骨架都一样，但"糖"和"钩子"长相不同：

- **第 1 章 · 困境爆点**：把主角扔进具体、难堪、要命的局，末尾抛钩子（悬念 / 反转 / 金手指征兆），留"然后呢"的强问号。
- **第 2 章 · 转机落地**：金手指 / 重生 / 系统 / 秘密身份挑一样亮，小试牛刀给颗糖——男频给打脸、女频给心动、悬疑给线索拼图。
- **第 3 章 · 升级打脸**：第一次正面冲突收口，配角吃瘪，主线铺开，章末再抛更大钩子逼进第 4 章。

---

## 五、六种钩子，分赛道用（附怎么套自己身上）

下面六种，不是让你抄，是照结构改你自己的开篇。每条标了适合哪类：

1. **危机钩子（女频 / 悬疑）**：结婚三年，老婆第一次主动吻我，唇上却抵着一把刀。
2. **反差钩子（男频）**：全宗门都笑我废柴，直到我剑指苍穹时天黑了半边。
3. **金手指钩子（男频 / 悬疑）**：重生回高考前一天，我先把前世害死我的人写进了黑名单。
4. **情绪共鸣钩子（全赛道）**：加班到凌晨三点，银行卡三位数，房东说再不交租东西扔出去。
5. **悬念钩子（悬疑 / 女频）**：我捡了本日记，最后一页写——别信你身边任何一个活人。
6. **对话炸场钩子（全赛道）**："你敢动她一下试试。"他声音很轻，"试试你就知道了。"

**套法**：拿你第 1 章开头，问自己这一句是动作、冲突、还是反常？都不是，就换成上面任一种的结构，只换你的人物和处境，钩子立刻立住。

## 六、落到字上，几句实在规矩

手机上读者靠"划"不靠"读"，这几条我见过新手栽得最狠：

- **句子别长**，一句压在二十来字，三行必换行。别写长从句，读者一眼扫不过就走。
- **少用形容词，多用动词**。把"他愤怒地狠狠一脚踹翻桌子"改成"他抬脚，桌子翻了"，情绪让读者自己补。
- **别解释，演给他看**。不写"他很害怕"，写"手在抖，钥匙插了三次没进锁孔"。
- **章末别收平**。每章最后一句要么悬念要么反转，绝不在章末说"这一天就这样过去了"。
- **说人话**。我这份东西自己也在尽量这么干——能说"给到"就不说"交付"，能说"对上"就不说"对齐"。你写的时候也一样，读者要听你唠故事，不是读公文。

## 七、这些坑，踩了就废（分两档）

**会下架（红线，别碰）：**
- 敏感 / 政治 / 擦边内容，直接封号下架。

**会降权（读者和算法一起嫌）：**
- 开局无敌 / 龙傲天：主角一上来啥都碾压，没起伏，读者秒腻。
- 大段诗词文言文掉书袋：手机上谁看。
- 回忆杀、前情提要超一屏：还没进故事先疲劳。
- 多 POV 乱切：开篇换视角，读者记不住谁是谁。
- 圣母 / 无脑善良主角：现代读者不爱。
- 水字数：重复心理活动、无意义环境描写凑篇幅，算法认得出来。
- 标题党 / 简介货不对板：承诺的和写的不一样，留存断崖。

---

## 八、书名、简介、首章，得是一伙的

最常见扑街：简介写得天花乱坠，首章没接住，读者感觉被骗。对齐很简单——简介抛的钩子，首章必须接。三条简介模板，挑搭的：

- **反差型**："人人都以为她是废柴，直到那天……"
- **悬念型**："我杀了人，可凶手是十年后的我。"（这招和上面危机 / 悬念钩子一个路数，首章就把"凶手是谁"接住）
- **爽点型**："重生一次，欠我的，我一个个清算。"

写完首章回头看简介：承诺的爽点给到了吗？没给就改首章，别改简介去将就。

---

## 九、发布前，拿这套客观标准过一遍

别问"读者会不会想看"，问能打勾的：
- [ ] 首句是动作 / 冲突 / 反常吗？（不是就改）
- [ ] 前 3 段里有没解开的悬念吗？
- [ ] 每章末句是钩子或反转吗？
- [ ] 金手指 / 核心设定前 3 章亮了吗？
- [ ] 有没有超一屏的背景 / 回忆堆砌？（有就砍）
- [ ] 简介承诺的爽点首章交付了吗？
- [ ] 踩了第七条任一条吗？（踩了就改）

---

## 十、赶时间的话，只保住这三样

新手最容易犯的错，是把上面全摊开反而不会写。真要赶，先守住这三个，其余慢慢调：

1. **首句即冲突**——别铺垫，第一句就出事。
2. **章末留钩**——每章最后一句憋住，逼人点下一章。
3. **金手指前三章亮**——读者得早点看见"这书凭啥爽"。

这三样稳住，开篇就死不了。

## 十一、改前改后，看差距

**男频：**
改前：林轩是青云宗外门弟子，平日刻苦但天赋平平，常被人嘲笑。这一日，他又在天台打坐……
改后：林轩今天差点死。不是修炼走火，是大师兄把他从天台踹了下去——只因他多看了一眼宗主的女儿。
差别：背景全删，首句即危机；具体事件替掉"被嘲笑"的概括；埋"为什么多看一眼就要死"的钩子。

**女频：**
改前：苏晚今年二十二，普通上班族，最大愿望安稳过日子。直到那个雨夜……
改后：结婚三年，顾沉从没碰过她。可今早，她在丈夫手机里，看见自己明天车祸身亡的提醒。
差别：首句立住反常关系，第二句砸悬念，读者立刻想知"他是不是凶手 / 能不能救她"。

**都市男频（换个不同设定，避免老用同一例）：**
改前：陈默是个普通程序员，朝九晚五，生活平淡，最大爱好下班写代码。
改后：陈默的代码被人抄去卖了八千万。抄他的，是刚分手的女朋友，正挽着投资人笑。
差别：首句即冲突（被背叛+巨额利益），信息差埋钩，读者想知道他怎么翻盘。
