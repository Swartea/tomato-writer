# 番茄写作助手 · 功能实测文案样本（按真实 prompt 复刻）

> 复刻方式：用工具 `webview/src/aiService.ts` 中 `TOMATO_BASE_SPEC` + 各 PROMPT 原文作 system 指令，
> 用 `App.tsx` 内置示例库（男频《龙王令》demo 章节 / 女频顾寒川线 / 悬疑死者日记线）作输入，
> 由主理人按该 prompt 逻辑生成「工具在给定配置下会产出的文案」。
> 非真实 API 调用（工具需 VS Code + DeepSeek Key，且默认模型名 `deepseek-v4-flash` 在 DeepSeek 产品线中并不存在）。
> 目的：验证各环节 prompt 的设计是否导致「落后」文案。
