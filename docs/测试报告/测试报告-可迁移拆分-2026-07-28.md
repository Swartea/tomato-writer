## 真实 AI 在线复测

为避免向第三方模型发送未发布正文，本轮使用完全合成、隔离的小说项目，不读取或上传用户真实小说内容。

| 项目 | 结果 |
|---|---|
| 接口 | `https://api.minimaxi.com/v1/chat/completions` |
| 模型 | `MiniMax-M3` |
| 工作流 | 章节生成 → AI 审校修订 → 候选保存 → 人工批准 |
| 请求结果 | 成功 |
| 总耗时 | 约 14 分 40 秒 |
| Prompt 版本 | `2026.07-v3` |
| 原候选 | 1447 字，对话占比 10% |
| 审校修订版 | 1311 字，对话占比 14% |
| 候选状态 | `candidate` → `approved` |
| 正式稿 | `chapters/001.md`，3723 字节、1415 个 Unicode 字符 |
| 自动备份 | 通过，批准前生成 1 份备份 |
| 关闭重开 | 通过，重新打开后仍显示“已批准” |
| 数据版本 | 保持 `schemaVersion: 2` |

最新版扩展进程对旧进程写入的候选完成了兼容补齐：模型响应未提供 `aiSmell` 数值，加载后规范化为 `0/100`，候选文件随后可正常批准和重开。

真实模型质量检查发现两处偏差：

- 审校文字声称对话占比已提升到 18%–22%，程序重新统计实际为 14%，仍未达到本书 35%–50% 的当前目标。
- 生成与审校总耗时明显偏长，虽然最终成功落盘，但会让用户长时间停留在运行态，建议后续增加阶段进度、单阶段耗时记录和更明确的超时提示。

配置持久化检查未通过：真实调用前界面显示“已配置”，重新加载 VS Code 窗口并进入最新版扩展后显示“未配置”。由于 API Key 不应由测试程序读取或回显，本轮没有绕过 SecretStorage 再次注入密钥；应单独排查普通设置与 SecretStorage 的写入键、扩展升级兼容和重载恢复。
