# 番茄写作助手 · 生产流程概览

> 目标：用一张图 + 文字把"软件怎么把灵感变成一章正文"讲清楚，帮助快速建立项目认知。
> 适用版本：v0.4.1（monorepo：`packages/core` + `packages/contracts` + `webview`）

---

## 一、项目定位

一个跑在 **VS Code** 里的网文（番茄风格）写作助手。核心理念：**AI 只生成"候选稿"，绝不覆盖你的正式正文**。每一次产出都经过"生成 → 审校 → 硬指标闸门 → 人工批准"四道关，才落盘成正式章节。

┌───────────────▼─────────────────────────────────────────────┐

## 三、端到端生产流水线

| 阶段 | Tab | 核心 Workflow 函数 | 作用 |
|------|-----|--------------------|------|
| 1. 策划与文风 | 策划与文风 | `brainstorm` / `recommendSubtype` / `strengthenPlanning` / `deriveStyle` | 灵感→书名/卖点/设定；AI 推荐子类型；补强策划案；生成文风档案 |
| 2. 剧情大纲 | 剧情大纲 | `generateOutline` | 大幕到章节，含黄金三章、伏笔铺设/回收、章末钩子 |
| 3. 创作资产 | 创作资产 | `generateAsset` | 人物 / 世界观 / 伏笔 三类资产 |
| 4. 写作续写 | 写作与审批 | `generateChapterCandidate` | 组装上下文→生成→审校→闸门→候选稿 |
| 5. 审批定稿 | 写作与审批 | `approveCandidate` | 候选稿批准→写入 `chapters/` 正式正文 |
| — 辅助 | AI 助手 | `runAssistant` / `complete` | 自由对话 / 任意 messages 补全 |
| — 辅助 | 统计 | （读取 ProjectData） | 字数 / 章节 / 对话比等真实统计 |

前 4 阶段统一打到 **AI 引擎**（宿主 `fetch` 代理，绕过 webview CSP），产物落地到本地 `readable-txt` 布局。

## 四、章节续写内部链路（`generateChapterCandidate`）

```
① buildContext 组装上下文
   前3章 + 相关人物 + 待处理伏笔(到期过滤)
        ↓
② writingPrompt 生成正文
   模型输出 content · 去AI味六维度硬约束
        ↓
③ reviewPrompt 审校
   aiSmell 评分(0-100) + revisedContent 修订稿
        ↓
④ metrics + 硬指标闸门
   字数 1200-1500 · 对话比 35-50%(男频脑洞) · candidateViolations
        ↓ (violations 非空 → 回环重生成)
⑤ approveCandidate → 写入正式正文
```

- 第 ④ 步用**真实** `metrics` 函数算指标，`candidateViolations(content, revisedContent, target)` 判定是否超窗。
- 超窗时橙色回环回第 ② 步重生成（已实测：窗口极窄，真实模型常需 2+ 轮）。
- 只有 `approveCandidate` 才会把内容写进 `chapters/`——安全护栏。

---

## 五、关键设计理念

1. **候选稿安全护栏**：AI 产出存 `generations/`，批准前绝不碰正式正文。
2. **硬指标闸门**：字数 + 对话比双闸门，`candidateViolations` 守窗口。
3. **伏笔生命周期**：`planned → planted → paid`，状态机追踪铺设/回收。
4. **文风档案 + 负样本**：`styleProfile` 含 bannedWords / bannedPatterns / referenceSamples / negativeSamples，驱动"去 AI 味"。
5. **题材策略卡**：`GENRE_TACTICS` 按二级题材给写法（男频脑洞放开 / 收敛档），含首句、书名公式、对话比目标、3 坑。
6. **热梗自动嵌入**：`HOT_MEMES_2026` 动态注入，每章≤1。

## 七、已知问题（来自文案功力与逻辑测试 2026-07-29）

- **P1（逻辑矛盾）**：`TRACK_RULES.male` 永远输出"放开"文案，收敛档题材（都市日常/现实题材/乡村生活）同时收到放开+收敛矛盾指令，收不住。
- **P2**：`dialogueRatio` 分母用 `text.length`（含空白换行），正文换行多时对话比被压低，与字数口径（去空白）不一致。
- **P3**：`buildContext` 只提醒"即将到期回收"的伏笔，不提醒"本章应铺设"的——大纲伏笔标记遗漏时链路静默断裂。

详见 `测试报告/测试报告-文案功力与逻辑-2026-07-29.md`。
