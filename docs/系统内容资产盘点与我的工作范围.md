# 番茄写作助手 · 系统内容资产盘点 & 我的工作范围

> 本文是 **Content Creator（内容创作专家）** 对 `tomato-writer` 系统的内容资产梳理，
> 目的是把"我该干什么活"从"写飘在文件系统的策略文档"纠正为"经营系统内部的内容资产"。

---

## 1. 系统是什么（干的是什么活）

- **形态**：VS Code 扩展（`package.json` 明示"专为番茄小说**短篇**写作设计"）。
- **核心场景**：作者用它从 0 到 1 策划一本番茄短篇，并持续写作、用 AI 辅助、看数据。
- **6 个内容面板**：开篇策划 / 写作编辑器 / 大纲 / 角色 / AI 助手 / 统计。
- **AI 引擎**：webview → extension host `fetch` 代理 → OpenAI 兼容 API（默认 DeepSeek）。

### 关键认知：系统的"内容大脑"在代码里，不在文档里
真正决定作者看到什么、写出什么的内容资产有两类：

**A. AI Prompt 库（`webview/src/aiService.ts`）**
| 常量 | 作用 |
|---|---|
| `SELLPOINT_PROMPT` | 一句话卖点生成 |
| `NAMING_PROMPT` | 角色名生成 |
| `BOOK_TITLE_PROMPT` | 爆款书名生成 |
| `OUTLINE_PROMPT` | 黄金三章 + 分章大纲 |
| `WRITING_PROMPT` | 续写/正文风格控制 |
| `AI_DETECT_PROMPT` | AI 味检测 |
| `LOGIC_CHECK_PROMPT` | 逻辑漏洞检查 |
| `EDITOR_REVIEW_PROMPT` | 番茄主编审稿评价 |

**B. 硬编码示例库（`webview/src/App.tsx` 等）**
- 题材卡描述（女频 9 个 + 男频 8 个赛道，含"完读率76%"等数据）
- 卖点示例库 `SELLLPOINT_EXAMPLES`
- 开篇 6 种模板 `OpeningTemplate`
- 角色卡 demo（林小雨/顾寒川/沈婉清/陆建明/苏青禾…）
- 两章 demo 正文 `DEMO_CHAPTER_1/2`（"雨夜邂逅"故事）
- 策划页字数规划文案、投稿须知、标题公式

---

## 2. 作者用这个系统"看什么内容"

1. 自己的稿（写作画布 + 章节列表）
2. 策划元数据（题材 / 卖点 / 标题 / 开篇设计）
3. 大纲（主线 · 节奏 · 分章细纲）
4. 角色卡 + 世界观设定
5. **AI 生成物**：卖点清单、书名清单、续写、润色、大纲、角色名、主编评价、逻辑检查、AI 味检测
6. 统计（字数 / 连续天数 / 目标达成）
7. **隐性教学示范**：题材卡描述、卖点示例库、开篇模板、角色卡、demo 章节——产品教作者"番茄打法长啥样"的样板间

→ 第 5、7 类，正是**我的内容产出职责所在**。

---

## 3. 我（Content Creator）该干什么活

### 定位
**本产品的内容 / 方法论负责人**：让系统跑出来的每一个字、每一条示范，都符合 2026 番茄短篇的真实打法，且内部自洽、不自带 AI 味。

### 任务清单（按优先级）

**P0 — AI Prompt 库审计 & 重写**
- 8 个 prompt 逐条审：知识是否 2024-era 过时？是否与面板其他文案矛盾？自身是否带 AI 味（ ironic：教别人去 AI 味，自己却写"值得注意的是"）？
- 重写使其符合 2026 番茄**短篇**逻辑 + 题材分轨 + 黄金三章硬指标。
- 重点纠偏：`OUTLINE_PROMPT` 写"3-5 万/20-30 章"但面板说悬疑 5-8 万、古言 8-12 万；`WRITING_PROMPT` 写"单句≤15字"偏激进。

**P1 — 硬编码示例库刷新**
- 题材卡描述：核对 2026 真实热度/完读数据，补"男频都市脑洞最热"等结论。
- 卖点示例库、开篇模板、角色卡 demo、DEMO 章节：让示范真正体现"前300字出钩子、章末留钩、男频打脸/女频心动/悬疑拼图"。
- DEMO 章节本身可作为"番茄标准开篇"样板，需按 v3 标准重写一遍。

**P2 — 内部矛盾清理**
- 钩子位置：策划页"前300字" vs 开篇设计"前500字" vs 投稿须知"前300字" → 统一口径。
- 字数区间：长短篇口径不一致 → 按赛道分档统一。
- 黄金三章模板：当前不分题材 → 按男频/女频/悬疑分别给。

**P2 — 之前研究的纠偏**
- `番茄小说套路研究-2026.md` 偏重**长篇**榜单（巅峰榜/畅销榜被长篇霸榜），本系统是**短篇**，需重做一版"番茄短篇 2026 套路"，并反推 prompt/示例。

**顺带提示（品牌一致性）**
- `DESIGN.md` 规定：品牌标用 `media/tomato-icon.svg`、**禁用 emoji 🍅**、导航禁用 emoji；
- 但 `extension.ts` NAV_ENTRIES 与 `App.tsx` 全用 emoji（🍅🎯✏️…）。属设计落地偏差，归品牌一致性范畴，可一并提示给开发。
